# AegisFlow — working agreement for Claude Code

Rust workspace (`crates/`), Swift CoreML bridge (`crates/aegis-ane-scorer/swift/`), CoreML model
builder (`models/build_model.py`, run with `harness/build_model.sh`), Cedar policies (`policies/`),
Obsidian brain (`brain/`, generated by `harness/sync_obsidian_brain.py`).

## Commands
- Build model artifacts: `bash harness/build_model.sh` (check only: `--verify-only`)
- Tests: `cargo test --release --workspace` (Rust from `~/.cargo/bin`)
- Benchmark: `cargo run --release -p aegis-bench -- --quiet-wait 300 --out artifacts/aegis_phase1_telemetry.json`
  (reduced smoke run: `--scale 0.1 --out target/bench-smoke.json`, which may not overwrite the canonical artifact;
  11/11 gate on the existing artifact: `python3 harness/run_tasks.py --only T18`, i.e.
  `cargo run --release -q -p aegis-bench -- --verify gate`; phase-1 sections: `--verify phase1`)
- Console + daemon: `bash harness/console.sh`, or `cargo run --release -p aegis-daemon` (serves 127.0.0.1:4173)
- API keys into `.env` (0600, values via stdin, never printed): `bash harness/configure_keys.sh`, or
  `cargo run --release -p aegis-daemon -- config status | config set NAME | config unset NAME`
- Whole harness: `python3 harness/run_tasks.py` (executes `harness/TASKS.json`, then syncs the brain)
- Brain sync dry run: `python3 harness/sync_obsidian_brain.py --vault DIR --bench FILE --kiro-root DIR --no-open`
- Post-task gate: `.claude/hooks/post_task_brain_sync.sh`

## Rules
- Numbers come from runs. Never type a latency, score or count into code, notes or JSON by hand;
  `.claude/hooks/verify_no_stubs.sh` rejects stub markers and literal telemetry values.
- A task is done when its `verify` command in `harness/TASKS.json` exits 0.
- Report missed targets as missed (`"pass": false`); `MLComputePlan` decides Neural Engine claims.
- Nebius, Tavily, PayPal Sandbox and chat webhooks are called only when their env credentials exist;
  tests use local listeners.
- Only a quiet full-scale benchmark run of the current sources decides the phase result: T18 fails on a
  reduced-scale, stale (sources fingerprint) or preliminary (busy machine, `run_conditions`) artifact.
- `brain/**`, `.kiro/specs/aegisflow-phase1/tasks.md` and `.kiro/specs/aegisflow-phase2/tasks.md` are generated;
  edit only inside `<!-- aegis:user:start -->` blocks (the sync fails if one changes).

Sub-agents: `.claude/agents/{systems-architect,core-builder,qa-reviewer,telemetry-ui}.md`.
